Setup Guide

Step-by-step instructions to deploy and configure the Social Media Manager for 80 hotel properties.

Prepared forIn-House Tech Team
DateMay 2026
Version1.0
Est. Setup Time6–8 hours total

Softmarche is a custom social media management system built for managing Instagram posting across multiple hotel properties. It connects to Facebook and Instagram via Meta's official API, stores data in a PostgreSQL database, and is hosted on Vercel.

ℹ️

All infrastructure used in this guide has a free tier sufficient to run 80 hotel accounts. No paid services are required to get started.

1
Get the Code
~10 minutes

Clone the repository from GitHub and install dependencies. Make sure Node.js 18+ is installed on your machine.

git clone https://github.com/parvinderdhillon90/softmarche cd softmarche git checkout claude/claude-md-docs-XQKWV npm install
✅

Confirm it worked: you should see a node_modules folder and no errors in the terminal.

2
Set Up the Database
~30 minutes · Free at neon.tech
  1. Go to neon.tech → sign up with Google or email → click Create Project → name it softmarche
  2. On the dashboard, click Connection string → copy the full string (starts with postgresql://)
  3. In the project root, create a file named .env with this content:
# Database DATABASE_URL="postgresql://user:pass@ep-xxx.neon.tech/softmarche" # Meta App (fill in after Step 3) META_APP_ID="your_app_id_here" META_APP_SECRET="your_app_secret_here" # Cron secret — any random string you choose CRON_SECRET="make-up-any-random-string-here"
  1. Run the database migration to create all tables:
npx prisma migrate dev --name init
✅

Confirm it worked: the terminal should say "Your database is now in sync with your Prisma schema."

3
Create a Meta Developer App
~60 minutes · Free at developers.facebook.com
⚠️

This step requires a Facebook account with admin access to the hotel Facebook Pages. If you don't have this, ask the client to add you as a Page admin first.

  1. Go to developers.facebook.com → click My Apps → Create App
  2. Choose Business as the app type → give it a name (e.g. Softmarche Manager)
  3. From the App Dashboard, click Add Product and add both:
    • Facebook Login
    • Instagram Graph API
  4. Go to App Settings → Basic → copy the App ID and App Secret → paste them into your .env file
  5. Go to App Review → Permissions and Features and request the following permissions:
    • pages_manage_posts
    • pages_read_engagement
    • instagram_basic
    • instagram_content_publish
    • instagram_manage_insights
ℹ️

While waiting for permission approval, you can still test with your own Facebook Pages in Development mode. Switch to Live mode only when going live with all 80 hotels.

4
Deploy to Vercel
~30 minutes · Free at vercel.com
  1. Go to vercel.com → sign up with GitHub
  2. Click Add New Project → select the softmarche repository
  3. Set the branch to claude/claude-md-docs-XQKWV
  4. In the Environment Variables section, add all 4 variables from your .env file:
    DATABASE_URL, META_APP_ID, META_APP_SECRET, CRON_SECRET
  5. Click Deploy

Vercel will give you a live URL like softmarche.vercel.app. The vercel.json file already in the project automatically sets up a background job that runs every minute to publish scheduled posts and sync Instagram data hourly.

✅

Confirm it worked: open your Vercel URL in a browser. You should see the All Properties dashboard (empty for now — accounts are connected in Step 5).

5
Connect Each Hotel's Instagram Account
~3–4 hours for 80 hotels · One-time per hotel

This connects each hotel's Facebook Page (and its linked Instagram Business account) to the system. Do this for all 80 hotels.

For each hotel:

  1. Open the live app → click Accounts in the sidebar
  2. In a new tab, go to developers.facebook.com/tools/explorer
  3. In Graph API Explorer:
    • Select your Meta App from the top-right dropdown
    • Click Generate Access Token
    • Select the hotel's Facebook Page and grant all 5 permissions from Step 3
    • Copy the token shown
  4. Back in the app → paste the token into the input field → click Connect
  5. The hotel's Page and Instagram account appear in the list
💡

Tip: Do hotels in batches of 10–15 per session. Each connection takes about 2–3 minutes once you're familiar with the flow.

⚠️

Each hotel's Instagram account must be a Business or Creator account linked to their Facebook Page. Personal Instagram accounts are not supported by Meta's API.

6
Set Post Targets Per Hotel
~30 minutes for all 80 hotels
  1. Open the live app → go to All Properties
  2. Click Refresh All to pull the first data sync from Instagram
  3. On each hotel card, find the target number (shown as e.g. 18 / 20)
  4. Click the underlined 20 → type the agreed monthly target → press Enter

The system will then colour-code each hotel based on its progress towards the target:

ColourStatusMeaning
● IssuesRedMissed posting days OR today's post not done yet
● Near targetAmberWithin 10% of completing the monthly target
● On trackGreenPosting consistently, no missed days
● Target metBlueMonthly post target fully reached
